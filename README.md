Array Traversal in C

This repository contains a C program to traverse and display elements of an array entered by the user.

📌 Description

Array traversal is the process of accessing each element of an array sequentially.
This program takes input from the user, stores the elements in an array, and then prints them using a loop.

🧠 How the Program Works

The user enters the number of elements.

The user inputs the array elements.

A for loop is used to traverse the array.

Each element is printed in order.

🛠️ Features

User input for array size and elements

Simple array traversal using loops

Beginner-friendly C program

Clear input and output format
